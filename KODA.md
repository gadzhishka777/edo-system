# Обзор проекта

**EDO** — корпоративная система электронного документооборота (СЭД). Система предназначена для управления документами, служебной перепиской, контактами и справочниками с поддержкой проверки электронных подписей (ГОСТ-алгоритмы).

Проект реализован в виде клиент-серверного приложения с раздельными frontend и backend частями, а также включает вспомогательный сервис для проверки цифровых подписей Go GOST.

## Технологии

| Компонент      | Технология                                      |
| -------------- | ----------------------------------------------- |
| **Frontend**   | React + TypeScript, Material UI (MUI), React Router |
| **Backend**    | FastAPI (Python), SQLAlchemy (async), Pydantic  |
| **База данных**| PostgreSQL (предположительно, через docker-compose) |
| **Сервер**     | Nginx (frontend proxy)                          |
| **Контейнеризация** | Docker + Docker Compose                   |
| **Электронные подписи** | Go GOST сервис (ГОСТ Р 34.11-94, ГОСТ Р 34.11-2012) |

---

## Основные функциональные возможности

1. **Управление документами** — загрузка, хранение, просмотр PDF-документов, проверка электронных подписей (ГОСТ), маппинг подписантов на штампы, кастомные папки.
2. **Служебная переписка** — создание и управление письмами между организациями, статусы писем.
3. **Контакты и организации** — справочник организаций и контактов.
4. **Справочники (Registries)** — управление справочными данными.
5. **Сотрудники** — управление сотрудниками, ролями, авторизация сотрудников.
6. **Почтовый модуль** — взаимодействие с почтовыми серверами.
7. **Админ-панель** — администрирование системы.
8. **Проверка лицензий** — проверка лицензии при загрузке приложения.
9. **Уведомления** — система push/realtime уведомлений через EventContext.
10. **Проверка ЭП** — интеграция с Go GOST сервисом для проверки открепленных электронных подписей.

## Сборка и запуск

### Frontend (React)

```bash
# Установка зависимостей
cd frontend
npm install

# Запуск в режиме разработки
npm start

# Сборка продакшн-версии
npm run build
```

## Правила разработки

- **Frontend**: TypeScript, компонентный подход на React с использованием MUI для UI. Роутинг через React Router. API-вызовы через централизованный клиент `edoApi.ts`.
- **Backend**: FastAPI с асинхронным SQLAlchemy. Разделение на модели (SQLAlchemy + Pydantic), маршруты (routers), сервисы (бизнес-логика) и утилиты.
- **Безопасность**: JWT-аутентификация, разграничение доступа по организациям (организационная изоляция документов).
- **Конфигурация**: переменные окружения, файлы `.env` для разных сред (`.env`, `.env.example`, `.env.production`).

## Заметки

- Проект использует `go-gost` сервис для проверки ГОСТ-подписей — встроенный REST API сервер, внесённый в реестр программ для ЭВМ (рег. № 2023683037).
- В проекте реализована система маппинга подписантов на визуальные штампы для отображения на документах.
- Лог-файлы backend хранятся в `backend_err.log` и `backend_out.log`.
